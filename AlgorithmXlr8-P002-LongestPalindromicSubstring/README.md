# Longest Palindromic Substring

**Difficulty:** `Medium`

## Problem

Given a string s, return the longest palindromic substring in s.

If more than one substring of the maximum length is palindromic, returning the one whose expansion is found first while scanning left to right (the standard expand-around-center order) is acceptable.

Read s from standard input, and print the longest palindromic substring to standard output.

## Examples

### Example 1

**Input**
```
babad
```
**Output**
```
bab
```

**Explanation:** Both bab and aba are palindromes of length 3; scanning left to right, bab is found first.

### Example 2

**Input**
```
cbbd
```
**Output**
```
bb
```

**Explanation:** bb is the longest palindromic substring.

### Example 3

**Input**
```
a
```
**Output**
```
a
```

**Explanation:** A single character is trivially a palindrome of itself.
