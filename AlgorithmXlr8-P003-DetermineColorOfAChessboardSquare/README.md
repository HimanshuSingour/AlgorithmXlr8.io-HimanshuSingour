# Determine Color of a Chessboard Square

**Difficulty:** `Easy`

## Problem

You are given a chessboard square in algebraic notation, e.g. "a1".

A chessboard has 8 rows and 8 columns. The columns are labelled 'a' through 'h', and the rows are labelled 1 through 8. Squares alternate between two colors, White and Black.

Read the coordinate string from standard input, and print the color of that square: "White" or "Black".

## Examples

### Example 1

**Input**
```
a1
```
**Output**
```
Black
```

### Example 2

**Input**
```
h3
```
**Output**
```
White
```

### Example 3

**Input**
```
c7
```
**Output**
```
Black
```
