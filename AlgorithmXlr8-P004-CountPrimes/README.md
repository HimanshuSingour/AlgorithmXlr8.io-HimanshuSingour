# Count Primes

**Difficulty:** `Medium`

## Problem

Given an integer n, return the number of prime numbers that are strictly less than n.

Read n from standard input, and print the count of such primes to standard output.

## Examples

### Example 1

**Input**
```
n = 10
```
**Output**
```
4
```

**Explanation:** The primes less than 10 are 2, 3, 5, and 7, a count of 4.

### Example 2

**Input**
```
n = 0
```
**Output**
```
0
```

**Explanation:** There are no primes less than 0.

### Example 3

**Input**
```
n = 1
```
**Output**
```
0
```

**Explanation:** There are no primes less than 1.
